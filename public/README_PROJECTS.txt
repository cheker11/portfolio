ИНСТРУКЦИЯ ПО ДОБАВЛЕНИЮ ИЗОБРАЖЕНИЙ (INSTRUCTIONS FOR ADDING IMAGES)

Чтобы вставить свои фотографии и скриншоты работ в портфолио, поместите файлы
в папку /public или /public/projects со следующими именами:

1. ФОТОГРАФИЯ ПРОФИЛЯ (Hero Photo):
   - /public/profile.jpg
   (Если файл заменен, портфолио автоматически покажет вашу фотографию вместо стандартной).

2. КАТЕГОРИЯ 1: САЙТЫ С GITHUB (GitHub Web Sites):
   - /public/projects/github_site_1.jpg
   - /public/projects/github_site_2.jpg
   - /public/projects/github_site_3.jpg

3. КАТЕГОРИЯ 2: РАБОТЫ В FIGMA (Figma Designs):

   - /public/projects/figma_design_2.jpg
   - /public/projects/figma_design_3.jpg

4. КАТЕГОРИЯ 3: СТАРТАПЫ (Startups):
   - /public/projects/startup_1.jpg
   - /public/projects/startup_2.jpg
   - /public/projects/startup_3.jpg

Примечание: Если файл еще не загружен или временно отсутствует, портфолио 
автоматически и плавно переключится на фоновую тематическую заставку.
